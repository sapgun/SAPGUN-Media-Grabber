SAPGUN Media Grabber — Windows x64 (Avalonia 0.3 alpha)

This zip is a portable Avalonia build. It is NOT the stable Windows
installer (SAPGUN-Media-Grabber-Setup.exe / v0.2.2 Latest).

Extract the folder and run:

  SAPGUN Media Grabber.exe

It is self-contained and bundles yt-dlp, FFmpeg, and ffprobe.
You do not need to install .NET, Python, or FFmpeg separately.

This alpha does not replace the installed WinForms app. You can keep
v0.2.2 Setup.exe as Latest and try this folder next to it.

The in-app APP updater will download a new zip and reveal it in Downloads.
It will not silently run Setup.exe for this portable package.
